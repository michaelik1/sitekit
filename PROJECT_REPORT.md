# Отчёт о переработке проекта

## Результат

Проект превращён из набора жёстко зашитых страниц в небольшой файловый редакционный сайт. Vue-компоненты больше не нужно менять при добавлении статьи или видео: контент хранится отдельно, проверяется до запуска и собирается в компактные JSON-индексы.

## Новая архитектура контента

### Статьи

```text
content/articles/<slug>/
├── article.md
├── cover.svg
└── любые дополнительные изображения
```

`article.md` содержит YAML frontmatter и Markdown. Относительные изображения автоматически копируются в публичную директорию. Черновики проходят проверку, но не попадают в индексы и не копируются в `public/generated`.

### Видео

```text
content/videos/<slug>/
├── config.yml
├── poster.svg
└── video.mp4
```

В `config.yml` находятся заголовок, описание, рубрика, автор, дата, длительность, теги, статус и все параметры карточки. Видеофайл и постер лежат рядом.

### Настройки сайта

Название, описание, главный экран, сезонный блок и подпись футера находятся в `content/site.json`. Домен и редакционная почта переопределяются через `.env`.

## Что переработано

- новая редакционная визуальная система без шаблонных «AI-карточек»;
- адаптивные главная, архив статей, страница статьи, видеотека, страница видео, календарь, «О проекте», контакты, политика данных и страница ошибки;
- поиск и фильтрация материалов;
- честные даты, авторы и метаданные вместо случайных просмотров и лайков;
- удалена неработающая регистрация, старый URL перенаправляется в календарь;
- canonical URL, Open Graph, JSON-LD, RSS, sitemap и robots.txt;
- локальные видео без стороннего embed;
- security headers и production CSP;
- health endpoint `/api/health`;
- Docker multi-stage build, запуск от пользователя `node`, read-only filesystem в Compose и healthcheck;
- GitHub Actions для проверки проекта и сборки контейнера;
- команды создания статьи и видео;
- автоматическая валидация дат, статусов, обязательных полей, изображений, видео и относительных ресурсов Markdown.

## Контент

В проекте 36 статей: 24 исходных материала перенесены в Markdown и добавлены 12 новых:

1. Вершинная гниль томатов.
2. Профилактика фитофторы в теплице.
3. Летний полив яблони.
4. Смородина после сбора урожая.
5. Уборка и сушка чеснока.
6. Подготовка картофеля и погреба к хранению.
7. Уход за бочкой и водой для полива.
8. Обновление почвы в теплице.
9. Обрезка малины после плодоношения.
10. Подзимний посев овощей.
11. Подготовка дачи перед отпуском.
12. Подготовка компоста к осени.

В шести статьях добавлены отдельные наглядные схемы. Видеотека содержит 12 валидных MP4-заставок, чтобы интерфейс работал сразу.

## Основные команды

```bash
npm ci
npm run dev
npm run new:article -- slug "Заголовок"
npm run new:video -- slug "Заголовок"
npm run content:check
npm run check
```

## Что проверено в текущей среде

- сборка и повторная проверка 36 статей и 12 видео;
- создание тестовой статьи и тестового видео штатными CLI-командами;
- синтаксис TypeScript и всех `<script>`-блоков Vue;
- JSON и YAML конфигурации;
- наличие всех сгенерированных обложек, изображений, постеров и видео;
- локальные маршруты;
- все 12 MP4 прочитаны `ffprobe`;
- PNG и SVG ресурсы доступны;
- CSS имеет сбалансированную структуру;
- package.json и package-lock.json согласованы.

Полную Nuxt-сборку в этой песочнице выполнить не удалось: здесь Node.js 22.16, а lock-файл и Docker намеренно закреплены на Node.js 22.18; кроме того, npm registry недоступен, а нужные пакеты отсутствуют в локальном кэше. Для воспроизводимой проверки добавлен CI, а `npm run check` запускает подготовку Nuxt, TypeScript-проверку и production build.

## Перед публикацией

Главное обязательное действие — заменить файлы с `placeholder: true` на настоящие ролики. Остальные шаги перечислены в `PRODUCTION_CHECKLIST.md`.
